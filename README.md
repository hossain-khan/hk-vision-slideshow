# H.K. Vision - Slideshow 🖼️
A simple app to show slide show of HK Vision pictures

> [!TIP]
> To enter full screen mode in **Zen** or regular **Slideshow**, just press **`F`**. To exit, press **`Esc`**.

> [!TIP]
> To run this site locally, use Python's built-in server: `python3 -m http.server` then open `http://localhost:8000` in your browser.
